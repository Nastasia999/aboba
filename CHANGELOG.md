# Changelog

Все значимые изменения в этом проекте будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] - 2026-02-17

### Добавлено
- Итеративная модель распределения спроса по парковкам
- Построение графа пешеходной доступности из улично-дорожной сети
- Расчет матрицы происхождение-назначение (OD matrix)
- Итеративное распределение с учетом конкуренции
- Визуализация результатов (карты и графики)
- Поддержка конфигурации через JSON файл
- Встроенные функции вероятности (экспоненциальная и линейная)
- Поддержка пользовательских функций вероятности
- Модульная архитектура с объектно-ориентированным дизайном
- Логирование на всех этапах работы модели

### Модули
- `probability.py` - функции вероятности ходьбы
- `parking_config.py` - конфигурации модели
- `graph_utils.py` - утилиты для работы с графом
- `parking_core.py` - ядро модели
- `parking_project.py` - высокоуровневый API
- `visualization.py` - модуль визуализации

### Визуализация
- Карта загрузки парковок
- Карта покрытия кварталов
- Гистограммы распределения загрузки и покрытия
- Карта потоков OD pairs
