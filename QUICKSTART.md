# Быстрый старт

Это руководство поможет вам быстро запустить модель доступности парковок.

## Шаг 1: Установка зависимостей

```bash
pip install -r requirements.txt
```

## Шаг 2: Подготовка данных

Создайте папку `input_data/` и поместите туда ваши файлы:

```
input_data/
├── roads.gpkg      # Улично-дорожная сеть
├── origins.gpkg    # Кварталы/точки происхождения
└── parks.gpkg      # Парковки
```

### Требования к данным

**Roads (roads.gpkg):**
- Геометрия: LineString или MultiLineString
- Должен иметь CRS (систему координат)
- Опционально: поле времени или скорости

**Origins (origins.gpkg):**
- Геометрия: Point
- Обязательные поля:
  - `origin_id` (или другое, настраивается в config.json)
  - `D` (спрос, или другое поле, настраивается в config.json)

**Parks (parks.gpkg):**
- Геометрия: Point
- Обязательные поля:
  - `parking_id` (или другое, настраивается в config.json)
  - `C` (вместимость, или другое поле, настраивается в config.json)

## Шаг 3: Настройка конфигурации

Скопируйте пример конфигурации:

```bash
cp config.json.example config.json
```

Отредактируйте `config.json` под ваши данные:

```json
{
  "columns": {
    "origin_id_col": "origin_id",      // Название колонки с ID кварталов
    "origin_demand_col": "D",          // Название колонки со спросом
    "park_id_col": "parking_id",       // Название колонки с ID парковок
    "park_capacity_col": "C"           // Название колонки с вместимостью
  },
  "layers": {
    "roads_layer": "roads",            // Название слоя с дорогами
    "origins_layer": "origins",        // Название слоя с кварталами
    "parks_layer": "parks"             // Название слоя с парковками
  }
}
```

## Шаг 4: Запуск модели

```bash
python parking_model.py
```

## Шаг 5: Просмотр результатов

Результаты будут в папке `output_data/`:

- `parking_results.gpkg` - результаты расчетов (можно открыть в QGIS)
- `parking_results_iter_logs.csv` - логи итераций
- `visualizations/` - карты и графики

## Настройка функции вероятности

В `config.json` можно настроить функцию вероятности:

```json
{
  "model_config": {
    "probability_function": {
      "type": "builtin",
      "name": "p_walk_exponential",
      "parameters": {
        "t0": 5.0,      // Время до которого вероятность = 1
        "t1": 10.0,     // Время после которого вероятность = 0
        "p_at_t1": 0.2  // Вероятность в момент t1
      }
    }
  }
}
```

## Решение проблем

### Ошибка "Config file not found"
Убедитесь, что файл `config.json` существует в корне проекта.

### Ошибка "OD matrix is empty"
- Проверьте, что парковки находятся в пределах `cutoff_min` минут ходьбы от кварталов
- Увеличьте `cutoff_min` в config.json
- Проверьте, что граф построен корректно (дорожная сеть связная)

### Ошибка "No such column"
Проверьте названия колонок в `config.json` соответствуют вашим данным.
