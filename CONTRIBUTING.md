# Руководство по внесению вклада

Спасибо за интерес к проекту! Мы приветствуем вклад от всех.

## Как внести вклад

### Сообщение об ошибках

Если вы нашли ошибку:

1. Проверьте, не была ли она уже зарегистрирована в [Issues](https://github.com/yourusername/parking-accessibility-model/issues)
2. Если нет, создайте новую issue с описанием:
   - Что произошло
   - Что вы ожидали
   - Шаги для воспроизведения
   - Версия Python и установленные пакеты

### Предложение новых функций

1. Создайте issue с описанием предлагаемой функции
2. Объясните, зачем она нужна и как будет использоваться
3. Обсудите реализацию перед началом работы

### Pull Requests

1. **Форкните репозиторий**
2. **Создайте ветку** для вашей функции:
   ```bash
   git checkout -b feature/amazing-feature
   ```
3. **Сделайте изменения** и убедитесь, что код работает
4. **Добавьте тесты** если возможно
5. **Обновите документацию** если нужно
6. **Закоммитьте изменения**:
   ```bash
   git commit -m 'Add amazing feature'
   ```
7. **Запушьте в ветку**:
   ```bash
   git push origin feature/amazing-feature
   ```
8. **Откройте Pull Request**

### Стандарты кода

- Следуйте PEP 8 для стиля кода
- Используйте type hints где возможно
- Добавляйте docstrings для функций и классов
- Пишите понятные имена переменных и функций

### Тестирование

Перед отправкой PR убедитесь, что:
- Код запускается без ошибок
- Все импорты работают
- Примеры из README работают

## Вопросы?

Если у вас есть вопросы, создайте issue с меткой "question".

Спасибо за ваш вклад! 🎉
